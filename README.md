# PocketFly

**A fruit fly brain in your pocket.**

*A mobile sandbox for running and experimenting with the Drosophila connectome on Android.*

PocketFly runs a simplified neural simulation based on open Drosophila
connectome data **locally on your Android phone** — no server, no cloud — and
connects it to small interactive environments: sensory input in, descending
neuron activity out, a closed loop you can play, edit, ablate and measure.

```
Environment → Sensory input → Connectome runtime → Neural activity
     ↑                                              ↓
   Body  ←  Action decoder  ←  Descending neurons ←┘
```

> **What this is, honestly.** PocketFly is a *connectome-based simplified
> simulation*, not a complete biophysical fruit-fly brain. Connectome wiring
> is not a mind. The neural dynamics are simplified integrate-and-fire
> parameters, the sensory encoding and action decoding are artificial, and
> game behavior comes from structure plus hand-built decoders. Read
> [docs/scientific-limitations.md](docs/scientific-limitations.md) before
> drawing any conclusions.

## What can it do?

- **Run** a real closed loop on-device: a bundled 1,024-neuron sample
  connectome (synthetic, generated by our tools) drives mini games from
  actual spike propagation through a CSR graph in C++ (NDK), not random noise.
- **Play** three built-in closed-loop games: Light Chase, Flap, and Obstacle
  Avoidance.
- **Watch the brain**: live activity timeline, channel levels, pause /
  single-step / ×10-step, per-neuron inspector, runtime stats (steps/s,
  active neurons, memory).
- **Ablate**: disable neuron groups and see what behavior breaks. Reversible.
- **Create**: a world editor plus sensory/action mapping and a rule builder.
  Save and share games as a single `.pocketfly.json` file.
- **Experiment**: scripted stimulus protocols (visual bias, bilateral
  symmetry, ablation comparison, stimulus sweep) with JSON + CSV export.
- **Bring your own brain**: import `.pflybrain` connectome packages; the
  format and converter tooling are documented for the public MaleCNS dataset.

## Build it yourself

Requirements: **Git, JDK 17, Android command-line tools (SDK), NDK** — no
Android Studio needed.

```bash
git clone https://github.com/vexpaer/pocketfly.git
cd pocketfly
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Install on a device: `adb install app/build/outputs/apk/debug/app-debug.apk`

CI builds and tests every push: native C++ tests (plain g++), JVM unit tests,
lint, and the debug APK. Tags `v*` produce a GitHub Release with an APK.

## Architecture (30 seconds)

| Layer | Module | What it does |
| --- | --- | --- |
| Neural runtime | `:simulator` (C++17 + JNI) | CSR connectome, LIF dynamics, input injection, ablation, stats |
| Game/brain logic | `:core` (pure Kotlin) | Game schema, encoders, decoders, rules, physics engine |
| UI & orchestration | `:app` (Compose, Material 3) | Screens, simulation threads, snapshot publishing, import/export |

The connectome lives in compact binary files (CSR, structure-of-arrays) inside
a `.pflybrain` zip package. Nothing hot allocates per timestep; the UI reads
immutable snapshots published by a dedicated simulation thread.

Details: [docs/architecture.md](docs/architecture.md).
